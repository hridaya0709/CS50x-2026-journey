## Assignments:
* [Hello](https://cs50.harvard.edu/x/psets/6/hello/)
    - Implement a hello world program in Python.
* [Mario (more)](https://cs50.harvard.edu/x/psets/6/mario/more/)
    - Implement a program that prints out a pyramid of a specified height, implemented in Python.
* [Cash](https://cs50.harvard.edu/x/psets/6/cash/)
    - Implement a program that calculates the minimum number of coins needed to make change for a given amount of money, implemented in Python.
* [Credit](https://cs50.harvard.edu/x/psets/6/credit/)
    - Implement a program that validates credit card numbers and identifies the type of card, implemented in Python.
* [Readability](https://cs50.harvard.edu/x/psets/6/readability/)
    - Implement a program that calculates the approximate grade level needed to comprehend a given text, implemented in Python.
* [DNA](https://cs50.harvard.edu/x/psets/6/dna/)
    - Implement a program that identifies a person based on their DNA sequence, implemented in Python.
