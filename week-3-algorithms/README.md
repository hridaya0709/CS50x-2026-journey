# Week 3 - Algorithms

---

## Assignments:
* [Sort](https://cs50.harvard.edu/x/psets/3/sort/)
    - Sorts an array of n values using selection sort, bubble sort, and merge sort, implemented in C. 
    - Three hidden programs are provided where each one of the program implements one of the sorting algorithm. 
    - Identify the type of sort algorithm for those program based on given data sets.
* [Plurality](https://cs50.harvard.edu/x/psets/3/plurality/)
    - Simulate a plurality election where voters can vote for one candidate and the candidate with the most votes wins. 
    - If there is a tie, all candidates with the most votes win, implemented in C.
* [Runoff](https://cs50.harvard.edu/x/psets/3/runoff/)
    - Simulate a runoff election where voters can rank candidates in order of preference and the candidate with the least votes is eliminated until a winner is found, implemented in C.
* [Tideman](https://cs50.harvard.edu/x/psets/3/tideman/)
    - Simulate a Tideman election where voters can rank candidates in order of preference and the candidate who is condorcet winner wins, implemented in C.
