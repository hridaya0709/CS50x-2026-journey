## Assignments:
* [Volume](https://cs50.harvard.edu/x/psets/4/volume/)
    - Increase or decrease the volume of a WAV file, implemented in C.
* [Filter (less)](https://cs50.harvard.edu/x/psets/4/filter/less/)
    - Apply grayscale, sepia, reflection and bluer filters to .bmp images, implemented in C.
* [Filter (more)](https://cs50.harvard.edu/x/psets/4/filter/more/)
    - Apply grayscale, reflection, blur and edge detection filters to .bmp images, implemented in C.
* [Recover](https://cs50.harvard.edu/x/psets/4/recover/)
    - Retrieve the deleted .jpeg images from a memory card and save them in a directory, implemented in C.
